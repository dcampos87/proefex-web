# Moodboards D7 (TECH) y D8 (Grow Up) — Fase 1

**Estado:** `REQUIRES_PROEFEX_INPUT` — se presentan 4 direcciones completas en especificación escrita para elección. La producción visual de los boards (imágenes finales) quedó bloqueada: la generación automática de imágenes no está disponible en el entorno actual de Fase 1 (`PROEFEX_INPUT_REQUIRED` para producción gráfica o habilitar generación visual). Las especificaciones siguientes están listas para ejecutarse por un diseñador o generarse visualmente apenas esté disponible.

Cada dirección cubre los 13 elementos requeridos: color · tipografía · fotografía · vídeo · composición · UI · textura · iluminación · motion · hero · sección interior · mobile · transición.

## D7 — PROEFEX TECH

### Dirección A — "Sistema Encendido"

| Elemento | Especificación |
|---|---|
| Color | Fondo #001233 con capas rgba(255,255,255,0.04); naranja #F7931E solo como señal (CTA, líneas de datos activos); gráficos con #005A9E/#EFB729/#D64022 |
| Tipografía | Lexend Deca (títulos/cuerpo) + mono restringido a etiquetas `01 / DESARROLLO` (pendiente D11) |
| Fotografía | Cinematográfica low-key: salas técnicas, pantallas, manos sobre interfaces; grading frío + acento naranja |
| Vídeo | Solo hero de `/tech`, solo lg+, poster primero, pausa por visibilidad (D5 diferido: lanzar con poster) |
| Composición | Módulos-instrumento en grilla visible; espacio negativo amplio; numeración `01 —, 02 —` |
| UI | Paneles con borde 1px, marcas de encuadre en esquinas, hover que "enciende" el módulo (borde naranja + micro-datos) |
| Textura | Grid tecnológico al 3–6% de opacidad; campo de partículas-nodos sutil (≤60, pausado fuera de viewport) |
| Iluminación | Bajo key, rim light naranja, profundidad por capas |
| Motion | Firma: módulos que encienden en secuencia; easing técnico; stagger tight |
| Hero | Titular con revelado por líneas + panel de sistema animado + campo de red |
| Sección interior | Cards-instrumento con specs en mono; diagramas de flujo que se trazan |
| Mobile | Sin partículas ni parallax; módulos apilados; poster estático |
| Transición | Línea de datos que barre la pantalla al entrar/salir del universo |

### Dirección B — "Blueprint Cinemático"

| Elemento | Especificación |
|---|---|
| Color | Fondo #002254 con linework técnico; #005A9E en capas; naranja para cotas y crosshairs |
| Tipografía | Lexend Deca + anotaciones mono tipo plano técnico (cotas, coordenadas) |
| Fotografía | Campo: drones topográficos al atardecer, terreno, instrumentos; tratamiento cinematográfico con overlay de retícula |
| Vídeo | Igual que A (mismo régimen D5) |
| Composición | Estética de plano/blueprint: linework, cotas, marcadores de coordenadas; grilla protagonista |
| UI | Cards como "hojas de plano" con sellos de revisión; bordes técnicos |
| Textura | Papel técnico sutil, crosshairs, grid de precisión |
| Iluminación | Dusk cinematográfico en fotografía; linework luminoso sobre fondo |
| Motion | Firma: trazado de líneas (draw-on-scroll) y aparición de cotas; easing técnico |
| Hero | Drone en wireframe dibujándose línea a línea + titular |
| Sección interior | Diagramas isométricos, mediciones animadas |
| Mobile | Blueprint simplificado a 1 figura; sin trazados pesados |
| Transición | Barrido tipo "regla" con grid revelado |

**Criterio de elección:** A prioriza producto/sistemas (IA, software, cloud); B prioriza ingeniería de campo (geodesía, IoT, precisión). Ambos cumplen presupuestos de performance; las diferencias son de identidad más que de técnica.

## D8 — GROW UP

### Dirección A — "Editorial Viva"

| Elemento | Especificación |
|---|---|
| Color | Blanco dominante + banda amarilla #EFB729; coral #D64022 en subrayados y stickers; azul #002254 solo en texto/acento |
| Tipografía | Poppins XXL editorial (80–140px); Lexend Deca en cuerpo |
| Fotografía | Editorial autoral: personas creando, cultura, color vivo; recortes con máscaras orgánicas |
| Vídeo | Clips cortos en secciones (facade con thumbnail); nada autoplay |
| Composición | Collage con aire; asimetría moderada; texto envolviendo formas |
| UI | Cards editoriales con imágenes recortadas; subrayados animados; stickers gráficos |
| Textura | Recortes, flechas dibujadas a mano, círculos marcadores |
| Iluminación | Luz natural, luminosidad alta |
| Motion | Firma: subrayados que se dibujan + spring suave en entrada; stagger loose |
| Hero | Tipografía gigante con palabra destacada en color + collage mínimo animado |
| Sección interior | Split editorial con cita grande y fotografía protagonista |
| Mobile | Collage reducido a 1–2 piezas; titulares 56–72px manteniendo expresividad |
| Transición | Forma orgánica (blob) que revela la nueva sección |

### Dirección B — "Grafismo Kinético"

| Elemento | Especificación |
|---|---|
| Color | Paleta completa secundaria en formas geométricas: coral, amarillo, azul; naranja como puente de marca |
| Tipografía | Poppins inclinada/rotada, rompiendo la grilla; texto cinético por palabras |
| Fotografía | Cutouts con máscaras rugosas mezclados con campos planos de color |
| Vídeo | Igual régimen que A |
| Composición | Poster asimétrico: densidad alternada, elementos saliéndose del margen |
| UI | Cards-manifiesto; marquee de palabras (ESTRATEGIA · CONTENIDO · GROWTH) como separador |
| Textura | Streaks de motion blur, formas que morphean con scroll |
| Iluminación | Flat gráfico (sin sombras realistas) |
| Motion | Firma: texto cinético + marquee + morphing de formas; spring elástico |
| Hero | Composición kinética con tipografía rotada y formas reactivas al cursor (off en touch) |
| Sección interior | Ruta dibujada de proceso (Growth como camino) |
| Mobile | Cinética reducida: rotaciones leves, sin cursor-reactive |
| Transición | Cinta/marquee que cruza y revela |

**Criterio de elección:** A es más accesible/comercial (editorial cálido); B es más experimental y memorable (estudio creativo puro). Ambas respetan contraste AA y presupuestos (Doc 16).
